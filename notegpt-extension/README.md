# NoteGPT 浏览器插件（Chrome Manifest V3）

NoteGPT 是一个面向 ChatGPT 网页对话的轻量笔记插件，提供：

1. 捕捉当前 ChatGPT 聊天内容；
2. 在侧边笔记区对内容进行编辑、高亮与批注；
3. 通过浏览器打印能力导出 PDF。

## 安装方式

1. 打开 Chrome 扩展管理页：`chrome://extensions`；
2. 打开「开发者模式」；
3. 点击「加载已解压的扩展程序」并选择 `notegpt-extension` 目录。

## 使用说明

1. 打开 `https://chatgpt.com/` 或 `https://chat.openai.com/` 的任意对话页面；
2. 点击扩展图标，选择「捕捉并打开笔记区」；
3. 在右侧 NoteGPT 面板中：
   - 可直接编辑消息内容；
   - 选中文本后点击黄色/绿色/粉色高亮；
   - 在每条消息下方输入批注；
   - 点击「保存」可将当前对话笔记缓存到本地存储；
4. 点击扩展里的「导出 PDF」会打开打印页，选择「另存为 PDF」即可导出。

## 说明

- 数据保存在 `chrome.storage.local`，按聊天路径区分；
- 该版本以功能可用为主，后续可补充：
  - 批注锚点定位；
  - 多会话索引管理；
  - 更强的富文本导出（例如集成 jsPDF）。
